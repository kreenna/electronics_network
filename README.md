# Платформа для сети магазинов электроники
Backend-приложение на Django с REST API и админ-панелью для управления иерархической сетью по продаже электроники, включающей заводы, розничные сети и индивидуальных предпринимателей.

## Описание проекта
Приложение реализует управление трёхуровневой иерархической сетью поставщиков электроники:

Уровень 0 — заводы
Уровень 1 — розничные сети (могут ссылаться напрямую на заводы)
Уровень 2 — индивидуальные предприниматели (могут ссылаться на сети или заводы)

Каждое звено сети содержит:

- Название;
- Контактные данные (email, страна, город, улица, номер дома);
- Список продуктов с полями: название, модель, дата выхода на рынок;
- Ссылка на поставщика (предыдущее звено в иерархии, не обязательно предыдущий по уровню);
- Задолженность перед поставщиком (с точностью до копеек);
- Время создания (автоматическое заполнение).


## Технологии

- Python 3.13;
- Django;
- Django REST Framework;
- PostgreSQL;
- django-filter (для фильтрации);
- JWT или встроенная аутентификация Django.

## Установка и запуск

Клонировать репозиторий:

```
git clone https://github.com/yourusername/electronics-network.git
cd electronics-network
```

Создать и активировать виртуальное окружение:

```
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
.venv\Scripts\activate     # Windows
```

Установить зависимости:

```
pip install -r requirements.txt
```

Настроить базу данных и выполнить миграции:

```
python manage.py migrate
```

Создать суперпользователя для доступа к админ панели:

```
python manage.py createsuperuser
```

Запустить сервер:

```
python manage.py runserver
```

Фильтрация по параметру country.

Ограничение доступа — только активные сотрудники.

Документация API доступна по /api/docs/ (при настройке).

# Админство

Используйте Django Admin для управления записями.

На странице сети отображается ссылка на поставщика и реализованы фильтры.

Admin action позволяет очистить задолженность у выбранных объектов.

# Безопасность

Только активные сотрудники имеют доступ к API.

Аутентификация и авторизация реализуются средствами Django или дополнительно с Django REST Framework.
